# dsh-file-menu

右键对话里的文件名，弹出文件操作菜单。

## 用法

在文件链接或 `@` 引用的文件上右键：

| 菜单项 | 作用 |
|---|---|
| 打开文件 | 用 DSH 的文档预览打开 |
| 在默认应用打开 | 用系统默认程序打开 |
| 选择其他应用打开 | 弹 Windows 自带的「打开方式」 |
| 复制路径 | 复制文件绝对路径 |
| 在资源管理器中打开 | 在资源管理器里定位 |

## 安装

```bash
dsh plugin --profile desktop add github:starash07/dsh-file-menu
```

安装后重启客户端。

## 说明

- 仅 Windows。
- 工具调用行、交付卡片里的文件不接管（它们已有自己的入口）。
- 依赖 DSH 的界面结构，升级后可能需要适配。
